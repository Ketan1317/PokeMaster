## 📖 Overview

DexMaster is a modern Pokédex web application built using **React**, **Tailwind CSS**, and the **PokéAPI**. It provides a clean, responsive, and interactive interface to explore Pokémon, search by name, view detailed statistics, and maintain a personal favourites collection.

Designed with a premium Pokédex-inspired interface, the application focuses on smooth animations, modern UI/UX, and responsive layouts.

---

## ✨ Features

* 🔍 Instant Pokémon Search
* 📚 Browse 200+ Pokémon
* ❤️ Add & Remove Favourite Pokémon
* 📊 Detailed Pokémon Statistics
* ⚡ Official Pokémon Artwork
* 🎨 Modern Pokédex Theme
* 🌙 Dark Gaming UI
* 📱 Fully Responsive Design
* 🚀 Fast Loading Experience
* ✨ Smooth Hover & Animation Effects

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/DexMaster.git
```

Move inside the project

```bash
cd DexMaster
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
